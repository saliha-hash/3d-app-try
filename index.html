How to Read It

  1. Main scale: note the last millimetre mark before the vernier zero.
  2. Vernier scale: find the line that aligns with a main-scale line.
  3. Multiply the coinciding division by the least count and add the result.
Reading = Main Scale Reading + Vernier Scale Reading
Vernier Scale Reading = Coinciding Division × Least Count
Least Count = 0.05 mm
