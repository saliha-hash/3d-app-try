How to Read It

  1. Main scale: note the last millimetre mark before the vernier zero.
  2. Vernier scale: find the line that lines up exactly with a main scale line.
  3. Multiply that vernier division number by the least count and add.
Reading = Main Scale Reading + Vernier Scale Reading
Vernier Scale Reading = Coinciding Division × Least Count
Least Count = 0.05 mm
